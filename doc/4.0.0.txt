完整执行流程
1. 启动入口 (Application.main)
调用 CodestatsEngine.run(Application.class, args)

2. 引擎处理 (CodestatsEngine.run)
调用 ConfigLoader.load(args) 获取配置对象 Config

判断命令行是否包含 --gui：

如果没有 --gui → guiMode = true → 使用 GuiLauncher

如果有 --gui → guiMode = false → 使用 ConsoleLauncher

调用相应 Launcher.launch(config) 启动

3. 配置加载 (ConfigLoader.load)
三层覆盖，优先级从低到高：

读取默认配置文件 config.yaml（如果存在）
读取环境变量（CODE_STATS_ROOT_DIR，CODE_STATS_EXTENSIONS 等）
解析命令行参数（-d, -e, -x, -c, -t, -s, -o, -f, --no-gitignore）
构建并返回 Config 对象

4. 启动器执行
A. 控制台模式 (ConsoleLauncher)
调用 Pipeline.createDefault(config) 构建流水线

流水线结构（按顺序）：

CollectStage：使用 CompositeFilter（包含 ExtensionFilter、ExcludePathFilter、GitIgnoreFilter，若配置开启）递归收集文件，返回 List<Path>
ParallelAnalyzeStage：使用固定线程池（线程数由配置决定），对每个 Path 并发执行 AnalyzeStage.process()，返回 List<FileInfo>。进度监控可选传入，当前传入 null 未监控。
AggregateStage：将 List<FileInfo> 按配置的排序规则排序，然后逐个添加进 StatisticsResult 进行聚合，返回 StatisticsResult
OutputStage：根据 outputFormat 选择 ConsoleFormatter、CsvFormatter 或 JsonFormatter，并写入目标（控制台或文件），返回 Void。
调用 pipeline.execute(config.getRootDir())，触发整个流程

B. GUI 模式 (GuiLauncher)
在事件分发线程中创建并显示 CodeStatsGUI 窗口

用户在 GUI 界面中手动调整参数（根目录、扩展名、排除路径、线程数、排序方式等）

点击 “Start Analysis” 按钮触发 startAnalysis()

GUI 内部构建与命令行类似的流水线，但通过 SwingWorker 异步执行：

CollectStage 收集文件
创建 ProgressMonitor 并绑定到进度条
ParallelAnalyzeStage 并行分析（携带 monitor）
执行排序和聚合（手动排序 + 构建 StatisticsResult）
使用 tableModel 更新表格、在摘要区域显示统计信息
进度条与列表实时更新

5. 核心阶段详解
收集阶段：通过 Files.walkFileTree 遍历目录，过滤器链进行扩展名、排除路径、.gitignore 判断，收集所有符合条件的文件路径。

分析阶段（单文件）：

创建 FileInfo 对象

使用 LanguageDetector 检测语言（先通过扩展名，失败则读取首行 shebang）

根据语言对应的 LanguageSpec 读取注释标记；如果都无法识别，仅统计总行数

逐行读取文件，统计总行、空行、注释行（支持块注释跨行）、代码行，同时利用正则匹配统计复杂度关键字（if, else, for, while...）的出现次数作为复杂度

并行分析：将文件列表分发到线程池，每个文件调用 AnalyzeStage，完成后通过 ProgressMonitor 更新进度

聚合：依据配置的排序字段（lines/name/language/complexity）对 List<FileInfo> 排序，然后聚合到 StatisticsResult（累加各类行数、按语言汇总）

输出格式化：

ConsoleFormatter：表格风格文本输出

CsvFormatter：CSV格式（带转义）

JsonFormatter：使用 Jackson 输出结构化 JSON

6. 关键设计点
过滤器链：使用组合模式，支持灵活扩展（如 GitIgnoreFilter）

流水线模式：Stage 接口统一处理步骤，Pipeline 顺序执行

并行处理：ParallelAnalyzeStage 利用 CompletableFuture 和固定线程池

进度可插拔：ProgressMonitor 支持监听器，在 GUI 和控制台均可复用

配置优先级：YAML < 环境变量 < 命令行参数

语言检测：扩展名映射为主，辅以 shebang 识别无扩展名脚本

流程总结
项目以配置驱动、流水线架构实现代码统计，支持多种输出格式（Console/CSV/JSON）和用户界面（CLI/GUI）。文件收集、并发分析、结果聚合和格式化输出各阶段独立解耦，易于扩展新的过滤器、语言支持和输出格式。
