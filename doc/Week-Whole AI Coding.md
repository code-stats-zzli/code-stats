全周项目 AI 工程：从零一体化 JavaWeb 框架，教学级代码分析与合并示例
我用一周 + 100% AI 代码，从零实现了一个教学级 JavaWeb 框架 —— CodeStats
它包含：手写 HTTP 服务器、自研 IoC 容器、代码分析引擎、可视化仪表盘。
这不是产品，而是 教学演示 + 技术示例：展示如何用 AI 完成一个完整的、可运行的 JavaWeb 系统，并教会你底层原理。

一、什么是“全周项目 AI 工程”？
定义：一种软件开发范式——开发者在一周内，将一个小型系统的完整需求、架构设计、模块划分、约束条件等全部上下文，以结构化方式一次性提交给 AI。AI 在理解项目全貌后，直接生成所有源代码、配置文件和基础文档，交付一个可运行的系统。

英文缩写 WWAIC（读作“维克”），中文简称 “周全 AI 开发”。

构件	含义
全	整个项目的上下文、结构、约束一次性交给 AI，而非让 AI 逐文件查找
周	约定一周时间尺度，从零到可运行的小型系统
项目 AI 工程	以项目整体为单元，AI 作为主要生产力完成工程交付
与传统 AI 辅助的区别：传统方式是“打开一个文件，问 AI 如何写函数”，AI 看不到全局；而全周项目 AI 工程是 “一次性注入全部蓝图，AI 直接产出完整系统”。

二、CodeStats：教学级 JavaWeb 框架 + 代码分析合并示例
CodeStats 是我用“全周项目 AI 工程”范式开发的开源项目，它的定位是：

教学级 JavaWeb 框架演示：从零手写核心组件，让你理解 Web 服务器、IoC、请求分发的底层原理。

代码分析 + 合并示例技术：展示如何解析代码结构、合并多个代码片段、生成统一的分析报告。

一体化系统：包含后端、前端、数据库、AI 分析能力，全部代码由 AI 生成。

它不是一个“黑盒产品”，而是一个 可学习、可扩展、可演示的技术样板。
你可以用它来教学生 JavaWeb 基础，也可以作为 AI 生成完整项目的参考案例。

三、CodeStats 的技术架构（从零实现，无商业框架）
模块	实现方式	教学价值
HTTP 服务器	手写 ServerSocket 监听、解析请求行/头/体、封装 Request/Response 对象	理解 HTTP 协议、Socket 编程、线程模型
Servlet 容器	自研简易容器，支持 url-pattern 映射、动态加载 Servlet 类	了解 Tomcat 核心原理
IoC 容器	手写依赖注入：扫描类、实例化、自动装配（按类型/名称）	学习 Spring IoC 底层机制
代码分析引擎	解析 Java 源文件（AST 或正则），提取类、方法、字段、注释，合并多个项目的分析结果	理解静态代码分析技术
前端仪表盘	原生 HTML + CSS + JavaScript，AJAX 调用后端 API	不依赖前端框架，演示前后端分离
数据库交互	手写 JDBC 连接池（简化版），执行 SQL 生成分析报告	理解数据库连接和 ORM 基础
没有使用 Spring Boot、MyBatis、Vue/React 等现成框架。所有代码都是“从零写”的教学级实现。

四、实践过程：一周交付 CodeStats（全周项目 AI 工程实录）
第一天：准备全项目上下文（结构化描述）
我写了一份约 3500 字的项目蓝图，包含：

项目名称：CodeStats – 代码统计分析 + 合并展示平台

目标用户：学 JavaWeb 的学生、需要演示代码分析技术的开发者

功能清单：

手写 HTTP 服务器，支持静态资源和动态 Servlet
自研 IoC 容器，管理 Service 和 Dao 对象
代码上传功能（支持 .java 文件或多个文件 zip）
代码分析模块：统计行数、类数、方法数、注释率
合并分析：将多个上传项目的分析结果合并为对比报表
可视化仪表盘：用原生 ECharts 展示柱状图/饼图
技术约束：

不使用 Spring、Tomcat、Jetty、Netty 等现成框架

前端不使用 Vue/React/Angular，只用原生 JS

数据库使用 MySQL（但 JDBC 手写，不使用 MyBatis/Hibernate）

代码必须附带详细注释，达到“教学级”标准

目录结构规范：

text
src/
main/
java/
com.codestats/
server/          # HTTP 服务器实现
ioc/             # IoC 容器实现
servlet/         # Servlet 接口及实现类
analyzer/        # 代码分析引擎
db/              # JDBC 工具类
web/             # 前端资源（html, css, js）
resources/           # 配置
关键接口示例：HttpServletRequest、HttpServletResponse、BeanFactory、Analyzer 等伪代码定义。

第二天：一次性提交给 AI（使用长上下文模型）
我将上述蓝图 + 少量示例格式（JSON 样例、SQL 建表语句）作为 prompt，要求：

“根据以上描述，生成一个完整的 Java 项目（不使用任何第三方框架）。输出应包括：所有 .java 源文件、HTML/CSS/JS 前端文件、SQL 脚本、启动类（main 方法）、README 运行说明。确保代码可以一次性编译运行（使用 JDK 8+）。”

AI 在几个小时后返回了约 180 个文件，包括：

HttpServer.java（手写 ServerSocket 循环）

RequestParser.java（解析 HTTP 请求）

BeanFactory.java（简单 IoC 实现）

CodeAnalyzer.java（统计 Java 文件）

index.html + dashboard.js（原生 JS 调用 API）

第三天至第五天：人工验证与微调
AI 生成的代码存在少量编译问题：

缺失两个辅助类（StringUtils、FileUploadHelper）—— 让 AI 单独补全

一个循环依赖 bug（IoC 容器初始化顺序）—— 手动调整构造器注入顺序

前端 API 端口写死（localhost:8080）—— 改为相对路径

修复工作量：约 6% 的总代码量。核心业务逻辑（HTTP 解析、IoC 装配、代码分析）一次性正确。

第六天至第七天：收尾与发布
为每个关键类编写详细注释（说明设计思路和原理）

编写教学级 README：包含架构图、启动步骤、核心代码解读

录制 10 分钟演示视频（从启动到上传代码、查看合并报表）

开源发布到 Gitee

结果：CodeStats 项目仓库中 100% 的源代码由 AI 生成，且满足“教学级+无框架依赖+一体化”的要求。

五、这个项目的“革命性”体现在哪里？
演示 AI 的能力边界
它证明 AI 不仅能写函数、写类，还能设计并实现一个完整的 JavaWeb 系统，包括网络层、容器层、业务层、前端。

教学价值极高
因为未使用任何封装框架，每一行代码都暴露了底层原理。学生可以直接阅读 HttpServer.java 学习 Socket 编程，阅读 BeanFactory.java 学习 IoC。

代码分析 + 合并示例
展示了如何编写一个轻量级静态分析工具，并合并多个来源的数据。这本身就是一种可复用的技术示例，可用于代码质量平台、作业批改系统等。

可复现的方法论
我公开了完整的项目描述 prompt 和微调记录，任何人都可以用同样的方法，用 AI 生成自己的教学框架或演示项目。
